### So, what is this?

This site (dedicated to Monster White) is optimized for both mobile and desktop; while the desktop experience is superior, the mobile version is fully featured and offers the exact same content.

What _cool_ features does it have?

1. It has an actual themed intro sequence before letting you access the site (_pretty cool_).

2. It adapts to various resolutions "720p", "1080p", "2K", and "4K" so you won't see giant icons at 1080p or tiny ones at 4K.

3. It runs smoothly on Android and iOS, as well as in mobile view via browser developer tools (F12).

4. It supports two languages! The site defaults to **English**, but you can switch to **Italian** with a single click. **Japanese** language support is currently in the works! (_Should I add other languages?_)
